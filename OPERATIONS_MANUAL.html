1. Core Architecture (The Zero Re-Print Rule)

Every dynamic PVC smart card has a Permanent Security Token (e.g. 7KQ4M8X2). The physical QR code and NFC chip NEVER contain the client's direct link (e.g. Google Review link). They only contain the permanent redirect URL.

PHYSICAL PVC CARD (NFC Chip / Printed QR) │ ▼ PERMANENT DYNAMIC URL: https://dynamic-qr-1.vercel.app/c/{PUBLIC_TOKEN} │ ▼ SUPABASE EDGE REDIRECTION ENGINE │ ▼ READS "destination_url" IN DATABASE (Instant HTTP 302) │ ▼ CUSTOMER LANDS ON REAL DESTINATION (Google Review / Website / Instagram / WhatsApp / Menu)
⭐ Golden Rule for Operations: You can change the client's destination URL 1,000 times in the CRM dashboard. The physical card, printed QR code, and NFC chip never need to be replaced or reprinted.

3. How to Create a New Card

2
Card Generation Workflow
  1. Click Cards in the left sidebar menu.
  2. Click the blue "+ Create Card" button in the top right header.
  3. In the modal dialog:
    • Destination URL (Optional): Enter the client's real link (e.g. https://g.page/r/your-google-review-link). If you don't have the link yet, leave it empty.
  4. Click Create Card in Database.
Automatic Allocation: The system automatically generates the next card number (e.g., CARD-0005), a cryptographic 8-character random token (e.g., V3GL4CCY), status READY, and dynamic URL https://dynamic-qr-1.vercel.app/c/V3GL4CCY.

4. Exporting QR Codes for PVC Card Printing

3
Downloading High-Resolution Print Assets
  1. Go to Cards → Click on the card row (or click QR Generator from the sidebar).
  2. On the right-side asset preview card:
    • Download {CARD-XXXX}.svg: Vector format for professional UV/PVC printers (lossless at any scale).
    • Download {CARD-XXXX}.png: High-resolution raster file for graphic designers.
  3. Confirm that the pre-print verification displays: QR Content: https://dynamic-qr-1.vercel.app/c/{TOKEN}.

5. NFC Chip Programming (Tag Writing Guide)

4
Encoding the Physical PVC Card Chip

Use any iPhone or Android smartphone with the free NFC Tools app (by Wakdev):

  1. Open NFC Tools → Tap Write.
  2. Tap Add a record → Choose URL / URI.
  3. Enter the permanent dynamic URL exactly:
    https://dynamic-qr-1.vercel.app/c/{PUBLIC_TOKEN} (e.g. https://dynamic-qr-1.vercel.app/c/V3GL4CCY)
  4. Tap OK → Tap Write / NDEF Format.
  5. Hold the smartphone against the PVC card until you hear the confirmation sound / checkmark.
  6. Quality Check: Tap the card with your phone. It should immediately open the browser and forward to the client's destination.

6. How to Change a Client's Real Link (No Re-Print Needed)

5
Updating Destination Links

When a client updates their review link, website, menu, or Instagram:

  1. Open the Admin Dashboard → Go to Cards.
  2. Search for the card by Card Number (e.g. CARD-0001) or Token.
  3. Click the Edit (Pencil) icon on the row (or open Card Details → Edit Destination).
  4. Enter the new destination URL (e.g. https://g.page/r/new-review-link).
  5. Click Save Changes to Supabase.
Instant Propagation: The database updates immediately. Anyone tapping the existing physical card will instantly land on the new destination URL.

7. Enabling & Disabling Cards (Security & Loss)

6
Card Lifecycle & Emergency Deactivation

If a customer loses a card, cancels service, or reports theft:

  • To Disable: Open the card details and click "Disable Card". Scans will immediately be blocked with an HTTP 403 / "Card Deactivated" screen.
  • To Re-Enable: Open the card details and click "Enable Card". Redirects will resume immediately.

8. Real-Time Scan Analytics

7
Verified Scan Tracking
  • Atomic Tracking: Every tap or QR scan increments the scan_count column in PostgreSQL.
  • Dashboard: View real-time aggregated metrics (Total Cards, Active Cards, Total Scans, Disabled Cards).
  • Card Details: View individual scan totals and timestamps for specific clients.
